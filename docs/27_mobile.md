# スマホ表示の方針

小さい画面では、**操作はふだん隠しておき、必要なときに出して選ばせる**のを基本にしています。画面の上半分が操作ボタンで埋まって、肝心の中身が見えない状態を避けるためです。

## 決まり

1. **ふだんは中身を大きく**。絞り込み・設定・追加のボタンは、1つのアイコン（`表示の設定` など）か丸い「＋」にまとめます。
2. **選ぶものはシートに出す**。下からせり上がるシート（`Modal`、PCでは中央のダイアログ）に、指で押しやすい大きな行（`ChoiceList`、1行48px前後）で並べます。小さなドロップダウンや、横にぎっしり並んだチップは使いません。
3. **追加は丸い「＋」**（`Fab`）。下のバーの上に浮かせます。PCでは同じ操作が画面上部の普通のボタンです。
4. **絞り込み中は印を付ける**。隠した設定が効いているとき、ボタンに青い点（`絞り込み中`）か、選んだ内容の名前を出します。
5. **PCで見えるものをスマホで消す／スマホ用を足す**のは CSS（`md:` の `hidden` / `md:hidden`）だけで行います（JavaScriptで画面幅を調べない。サーバー側の描画とずれないため）。PCの画面は変わりません。
6. 説明文は省く（PCだけ表示）。押す場所は指で押せる大きさ（高さ40px以上）にする。

## 部品

| 部品 | 場所 | 用途 |
|---|---|---|
| `Modal` | `src/components/Modal.tsx` | スマホでは下からのシート（つまみ付き・下の安全領域あり）、PCでは中央のダイアログ |
| `ChoiceList` | `src/components/mobile/ChoiceList.tsx` | 大きな選択肢の行（チェック付き） |
| `Fab` | `src/components/mobile/Fab.tsx` | 丸い「＋」ボタン（スマホだけ） |
| `FilterBar` | `src/components/mobile/FilterBar.tsx` | 一覧の上の絞り込み。スマホは1行を横にスワイプ、申請ボタンは丸い「＋」に。PCは従来どおり |
| `FoldCard` | `src/components/mobile/FoldCard.tsx` | スマホでは見出しをタップして開く折りたたみのカード（PCでは常に開いている）。閉じている間は右に「3件」などの一言。中の入力は閉じても消えない |

## 画面ごと

| 画面 | スマホでの見え方 |
|---|---|
| カレンダー | 見出しの下は「日／週／月」と「今日」、矢印と日付だけ。**メールアカウント・表示する人・ToDoの表示・Google連携は、右上の「表示の設定」シートの中**。追加は「＋」→「予定／ToDo」を選ぶ。月は予定を**点**で示し（予定=丸、ToDo=四角）、日をタップすると下にその日の一覧。週は今日の列が見える位置から始まり、時間の目盛りは左に固定 |
| ToDo | 見出しの下は「未完了／完了／すべて」の1本のバーと「担当」ボタン。担当の絞り込みはシート。追加は「＋」（内容を入れて Enter で保存）。チェックの丸は大きく |
| 経費・出張・振込申請 | 説明文は隠し、絞り込みは1行を横にスワイプ、申請は右下の丸い「＋」（金額の集計カードはそのまま） |
| 勤怠 | 打刻ボタンは2列の大きなボタン（高さ56px前後） |
| セキュリティ（管理者） | 上の数字は見えたまま、「ブロック中のアドレス」「ログイン方法」「検知したできごと」「アクセスの条件」「最近のログイン」は折りたたみ（ロック中のアカウントがあるときだけ開いた状態）。閉じた行に「0件」「未設定 8人」と出る |
| 管理設定（システム） | 13個の設定カードをそれぞれ折りたたみ（14,000px→短い一覧）。保存ボタンは下に固定のまま |
| プロフィール | パスワード変更・メールアカウント・パスキー・2段階認証・ログイン中の端末・アカウント情報・署名を折りたたみ |
| メール一覧 | 検索欄は**虫めがねを押すと出る**（検索中は開いたまま）。開くと入力欄にカーソルが入る |
