# テストサーバー用のデモデータ

テストサーバー（検証用の環境）に、すべての機能の例になるデータをまとめて入れるスクリプトです。

```bash
npm run seed:demo                        # デモデータを入れる（何度実行しても増えない）
npm run seed:demo -- --relax-security    # 入れたうえで「パスワード＋2段階認証」の必須と端末の確認をオフにする
npm run seed:demo -- --reset             # デモデータだけを消す
```

`DATABASE_URL`（と、口座を入れるための `ENCRYPTION_KEY_HEX`）は `.env` から読みます。接続先が自分のPC（`localhost`）で、データベースがまだ動いていなければ、**自動で起動し、終わったら止めます**（`npm run dev` と同じ仕組み。[11_setup_run_deploy.md](11_setup_run_deploy.md)）。実行すると、対象のデータベース（パスワードは伏せて）を表示します。

## 入るもの

| 種類 | 内容 |
|---|---|
| ユーザー（6人） | `demo-admin@demo.example.com`（管理者）・`demo-keiri@…`（経理担当）・`demo-sato@…`（営業部の課長）・`demo-tanaka@…`・`demo-suzuki@…`（業務委託）・`demo-yamada@…`（役員）。パスワードは `Demo-Passw0rd!`（`DEMO_PASSWORD` で変更可） |
| 組織 | デモ株式会社 › 営業部（部署長: 佐藤）・管理部（部署長: 経理）。役職は 部長 / 課長 / メンバー（既に同じ名前の役職があれば、それを使う） |
| メール | 共有メールボックス「営業チーム共有」（権限つき）に6件のやり取り（未対応・対応中・保留・完了、担当あり／なし、既読／未読、返信つき）。管理者の個人メールボックスに2件 |
| カレンダー・ToDo | 今日から数日分の予定（時間の重なり・終日を含む）、期限つきのToDo 6件（期限切れ・今日・完了済み・担当あり／チーム全体） |
| 勤怠・報告・給与 | 佐藤・田中の直近10営業日の打刻、鈴木の業務報告、給与明細（支払済・支払予定）、業務委託の報酬 |
| 経費・出張 | 経費申請（承認待ち・承認済・返金済・却下・会社負担）、出張申請（承認済・承認待ち、日当と宿泊手当つき）と、出張に紐付いた経費 |
| 口座・振込 | 受取口座（経理確認済・未確認）、取引先（確認済・未確認）、振込申請（承認待ち・振込待ち・振込済） ※ `ENCRYPTION_KEY_HEX` がないと入らない |
| 人事評価 | 評価期間（評価中・終了）、自己評価の提出済み・未提出、確定済みの結果 |

## 安全のために

- すべての行の id が `demo_` で始まります。実行は「同じ id を更新する」ので、増えません。**デモ以外のデータは変更も削除もしません**（`--reset` も同じ）。
- `NODE_ENV=production` では中止します（本当に本番へ入れるときだけ `--allow-production`）。
- `--relax-security` は、テストのためにログインの守りを弱めます。**本番や、外から見えるサーバーでは使わないでください**。付けないときは、初回ログインで2段階認証（認証アプリ）の設定が必要です。
- 実際のメール送受信はしません（デモのメールは画面に出るだけで、IMAP/SMTP の設定はありません）。

テスト: `e2e/seed-demo.spec.ts`（入れる → 全員ログインできる・各画面にデータが出る／再実行で増えない／`--reset` で消える／本番では止まる）。
