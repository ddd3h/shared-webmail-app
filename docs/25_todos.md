# ToDo（個人に1つ・共有メールはメンバーのToDoを見る入口）

「やること」の一覧です。**ToDoは個人に1つ**で、共有メールアカウントに紐づく一覧はありません。**期限を付けるとカレンダーにも表示**されます。共有メールを選ぶと、そのメンバーのToDoが見られます（見るだけ）。

## 画面

| 画面 | 内容 |
|---|---|
| `/todos` | 自分のToDoの一覧。入力して Enter ですばやく追加、チェックで完了／戻す、タップで編集・削除。状態（未完了／完了／すべて）で切り替え。「見るToDo」で共有メールを選ぶと、そのメンバーのToDoが並び、担当（全員／自分／各人）で絞り込み |
| `/calendar` | 期限の日のマスに、点線の枠のチップ（`☐ タイトル`、完了は `☑` と取り消し線、期限切れは赤）で表示。日を選ぶと右の一覧の下に「ToDo」が出て、そこでチェック・編集。「ToDoも表示」で出し入れ、「表示する人」の切り替えにも従う |

- メニュー: PCは上のバーに「ToDo」、スマホは「メニュー」の中（下のバーはメール・カレンダー・連絡先のまま）。
- マスに3行まで表示し、ToDoがある日は少なくとも1件はToDoを出します（超えた分は「+N件」）。

## 権限

| できること | できる人 |
|---|---|
| 自分のToDoを作る | ログインしている人は誰でも |
| ほかの人のリストにToDoを入れる | 同じ共有メールを見られる人どうし（相手にMattermostのDMが届く） |
| ToDoの編集・完了・削除 | そのToDoが**入っているリストの持ち主**と、**入れた人**。ほかの人は見るだけ |
| ほかの人のToDoを見る | 同じ共有メールを見られる人（共有メールを選んだとき） |

共有メールを共有していない人のToDoは見えません（個別の操作は 404）。「チーム全体」のToDoはありません（以前の分は、メンバー一人ひとりのリストに1件ずつ入りました）。

## 項目

内容（200字まで）・メモ（5000字まで）・期限（日付のみ。日本時間の日付）・誰のToDoか（`assignee_id`。必ず1人）。完了すると、完了した人と時刻を記録します。担当に選べるのは、そのメールアカウントを見られる人だけです。

「期限切れ」は、期限が**昨日以前**で未完了のもの（今日が期限のものは、まだ期限切れではありません）。

## 通知（Mattermost）

ToDoを**他の人のリストに**入れる（作成時、または付け替え時）と、その人にDMが届きます（内容・期限・入れた人・リンク）。自分のリストに入れたときは届きません。

## API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/todos?status=open\|done\|all&from=&to=[&mailboxId=&assignee=all\|me\|<userId>]` | 自分のToDo。`mailboxId` を付けると、そのメンバーのToDo（`assignee` で1人に絞れる）。`from`/`to`（YYYY-MM-DD、両端含む）は期限の範囲で、カレンダーが使う。`assignable` は、ToDoを入れられる人 |
| POST | `/api/todos` | 追加 `{title, description?, due_date?, assignee_id?}`（`assignee_id` を省くと自分のリスト） |
| PATCH | `/api/todos/:id` | 編集、または `{done: true/false}` |
| DELETE | `/api/todos/:id` | 削除 |

## データ

`todos`: `title`・`description`・`due_date`（DATE）・`assignee_id`（必須。リストの持ち主。ユーザーを消すと一緒に消えます）・`done_at`/`done_by_id`・`created_by_id`。`mailbox_id` はありません。以前のデータの移行は `prisma/migrations/20261124000000_personal_calendar`（担当なしのToDoは、そのメールのメンバー一人ひとりのリストに1件ずつ）。
