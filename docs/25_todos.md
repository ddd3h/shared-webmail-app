# 共有ToDo

チームで共有する「やること」の一覧です。**期限を付けるとカレンダーにも表示**されます。メールアカウント（チームのメールボックス）ごとに1つの一覧を持ち、カレンダーと同じ人が見られます。

## 画面

| 画面 | 内容 |
|---|---|
| `/todos` | 一覧。入力して Enter ですばやく追加、チェックで完了／戻す、タップで編集・削除。状態（未完了／完了／すべて）と担当（全員／自分／チーム全体／各人）で絞り込み |
| `/calendar` | 期限の日のマスに、点線の枠のチップ（`☐ タイトル`、完了は `☑` と取り消し線、期限切れは赤）で表示。日を選ぶと右の一覧の下に「ToDo」が出て、そこでチェック・編集。「ToDoも表示」で出し入れ、「表示する人」の切り替えにも従う |

- メニュー: PCは上のバーに「ToDo」、スマホは「メニュー」の中（下のバーはメール・カレンダー・連絡先のまま）。
- マスに3行まで表示し、ToDoがある日は少なくとも1件はToDoを出します（超えた分は「+N件」）。

## 権限（カレンダーと同じ）

| できること | 必要な権限 |
|---|---|
| 見る | メールアカウントの「閲覧」 |
| 追加・編集・削除 | 「返信」（カレンダーの編集と同じ） |
| 完了にする／戻す | 上に加えて、**自分が担当のToDoなら閲覧だけの人でも可**（内容の編集は不可） |

権限のない人には、ToDoの存在も分かりません（個別の操作は 404）。

## 項目

内容（200字まで）・メモ（5000字まで）・期限（日付のみ。日本時間の日付）・担当（チーム全体／メンバーのひとり）。完了すると、完了した人と時刻を記録します。担当に選べるのは、そのメールアカウントを見られる人だけです。

「期限切れ」は、期限が**昨日以前**で未完了のもの（今日が期限のものは、まだ期限切れではありません）。

## 通知（Mattermost）

担当を**他の人に**指定する（作成時、または付け替え時）と、その人にDMが届きます（内容・期限・指定した人・リンク）。自分を担当にしたとき、チーム全体のとき、担当が変わらない編集では送りません。

## API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/todos?mailboxId=&status=open\|done\|all&assignee=all\|me\|team\|<userId>&from=&to=` | 一覧。`from`/`to`（YYYY-MM-DD、両端含む）は期限の範囲で、カレンダーが使う |
| POST | `/api/todos` | 追加 `{mailboxId, title, description?, due_date?, assignee_id?}` |
| PATCH | `/api/todos/:id` | 編集、または `{done: true/false}` |
| DELETE | `/api/todos/:id` | 削除 |

## データ

`todos`（`prisma/migrations/20261030000000_add_todos`）: `mailbox_id`・`title`・`description`・`due_date`（DATE）・`assignee_id`・`done_at`/`done_by_id`・`created_by_id`。メールアカウントを消すとToDoも消え、ユーザーを消すと担当・作成者・完了者は空になります。
