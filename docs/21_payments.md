# 振込申請

画面は `/payments`（ナビの「振込」）。取引先の口座へ銀行振込をするための申請・承認・振込済みの記録です。実際の振込は銀行側で行い、このアプリはその依頼と記録を管理します。

## 流れ

```
申請（承認待ち）─┬─ 承認 ─→ 振込待ち ─→ （銀行で振込）─→ 振込済にする
                 └─ 却下（コメント必須）─→ 申請者が修正して再申請 → 承認待ち
```

- 申請項目: 振込先（取引先）、件名、請求金額（税込）、支払期日、請求書番号・日付（任意）、控除、振込手数料とその負担、備考、請求書（画像かPDF、1枚10MB・5枚まで）。
- 承認待ち・却下の間は、本人が編集・取り下げできます。承認後は変更できません。
- 管理者が2人以上いる場合、自分の申請は承認できません（他の管理者が承認）。
- 期日を過ぎても振込待ちのままの申請には「期日超過」が表示されます。

## 振込額の計算

```
振込額 = 請求金額 − 控除（源泉所得税など） − 振込手数料（先方負担のときだけ）
```

- 振込手数料が「当方負担」なら振込額から引かず、別途かかる費用として表示します。
- 控除と先方負担の手数料の合計が請求金額を超える申請はできません。
- 税額・源泉徴収額の自動計算はしません（申請者が金額を入力します）。

## 取引先と口座の管理

- 誰でも「取引先」から登録できます（申請時にその場でも登録可）。口座番号は **AES-256-GCM で暗号化**して保存し、管理者以外には**末尾4桁だけ**表示します。
- 登録された口座は**「口座未確認」**です。管理者が請求書・契約書と照合して「口座を確認済にする」を押すまで、その取引先宛の申請は**承認も振込済の記録もできません**（管理者が登録した場合は最初から確認済）。
- 管理者が銀行名・支店・預金種目・口座番号・名義を変更すると、**確認済が自動で外れ**、再確認が必要になります（口座のすり替え対策。変更は監査ログに残ります）。
- 同じ口座の二重登録はできません（口座番号まで照合）。
- 使用済みの取引先を削除すると、削除ではなく無効になります。

## 二重払いの防止

同じ取引先・同じ請求書番号の申請（承認待ち・振込待ち・振込済）はもう一度出せません。

## 承認・振込（管理者）

- 承認待ち: 振込先の口座情報（銀行・支店・口座番号・名義）と、金額の内訳、添付の請求書を見て承認/却下します。
- 振込待ち: 申請を選んで **CSV出力**（振込先・金額の一覧。銀行のネットバンキングへの入力や経理の照合用）と、**振込済にする**（振込日・メモを記録）。複数件をまとめて処理できます。
- CSVには口座番号を含みます（管理者のみ・出力は監査ログに記録）。Excelで開いても数式として実行されないよう、先頭が `= + - @` の文字は無害化します。**全銀フォーマットではありません**（全銀データは [22_zengin_transfers.md](22_zengin_transfers.md)）。

## Mattermost通知

申請・再申請 → 申請者以外の管理者、承認・却下 → 申請者、振込済 → 申請者。DMに口座情報は載せません。
