# 共有カレンダー

共有メールアカウント（メールボックス）ごとに1つのチームカレンダーを持ちます。画面は `/calendar`。

## 権限

メールボックスの既存権限をそのまま使います（追加の設定は不要）。

| 操作 | 必要な権限 |
| --- | --- |
| カレンダーを見る | `can_view` |
| 予定の作成・編集・削除、取り込んだ予定の名前変更、手動同期 | `can_reply` |
| 自分のGoogleカレンダーの連携・解除・表示設定 | `can_reply` |
| 他の人が連携したGoogleカレンダーの設定変更・解除 | `can_assign` |

個人メールボックスのオーナーは全権限を持ちます。

## 誰の予定か（人ごとの表示）

- すべての予定に「誰の予定か」があります（未指定＝チーム全体）。ローカル予定は作成時に、メールボックスを閲覧できるメンバーから選べます。
- Googleから取り込んだ予定は、**連携した人の予定**になります。
- 画面上部の「表示する人」で、人ごとに表示のオン/オフを切り替えられます（「全員」「自分のみ」ボタンあり）。人ごとに色が付きます。
- 閲覧権限があれば他メンバーの予定も見えます（Google予定は「予定ありのみ」が既定なので、詳細は共有されません）。

## Googleカレンダー連携（読み取り専用の取り込み）

- 連携は `calendar.readonly` スコープ。Google側の予定は変更しません。
- 1つのカレンダーに複数のGoogleカレンダーを連携できます（連携ごとに名前・色・表示設定）。
- 表示モード
  - **予定ありのみ（既定）**: ラベル（既定「予定あり」、連携ごとに変更可）だけを表示。タイトル・説明・場所は**DBにも保存しません**。
  - **詳細も表示**: タイトル・場所・説明を表示。
  - 「予定ありのみ」へ切り替えると、保存済みの詳細は削除されます。
- 取り込んだ予定は個別に**こちら独自の名前**へ変更できます（`title_override`）。再同期しても保持され、空欄にすると元の表示に戻ります。
- 同期: カレンダーを開いたとき（5分以上経過していれば自動）と「今すぐ同期」。範囲は過去31日〜未来366日。
- 終日予定は UTC の0時で保存（終了日は排他的）。

### セットアップ

Google Cloud Console で Calendar API を有効化し、OAuthクライアントのリダイレクトURIに次を追加します。

```
{NEXT_PUBLIC_APP_URL}/api/calendar/google/callback
```

`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` は連絡帳同期と共通です。トークンは暗号化して `calendar_google_links` に保存します。

## 日・週・月の表示

左上の「日／週／月」で切り替えます（はじめは月）。見ている日はどの表示でも引き継がれます（月で選んだ日 → 日 → 週 → 月）。

| 表示 | 内容 |
|---|---|
| 月 | 6週間のマス表示と、選んだ日の一覧（従来どおり） |
| 週 | 日曜〜土曜の7日を、時間軸（0〜24時）の縦並びで表示。はじめは8時の位置から見える |
| 日 | 1日だけの時間軸。予定の時刻・誰の予定か・場所が見える |

- ‹ › は表示に合わせて、1か月・1週間（7日）・1日ずつ動きます（ボタンの名前も「前の月／前の週／前の日」）。「今日」で今日に戻ります。
- 週・日の上にある「終日」の行には、終日の予定とToDo（期限の日）が出ます。時間のある予定は時間の位置に、長さのとおりの高さで表示します。**時間が重なる予定は横に並べて**表示します。日をまたぐ予定は、それぞれの日の分だけ表示します。
- 週の曜日の見出し（日付）をクリックすると、その日の「日」表示になります。
- 編集できる人は、**空いている時間をクリックすると、その時刻から1時間の予定の入力**が開きます（30分刻み）。
- 「表示する人」の切り替えと「ToDoも表示」は、どの表示にも効きます。
- 今日の列には現在時刻の線が出ます。スマホの週表示は、枠の中を横にスクロールします。
- 開いている表示と日はアドレスに入ります（`/calendar?view=week&date=2026-10-26`）。このアドレスで開けば同じ画面になり、アドレスがないときは前回の表示で開きます（ブラウザに保存）。

実装: `src/lib/calendar-view.ts`（表示する日・移動・見出し・重なりの並べ方。純粋な関数）、`src/components/calendar/TimeGrid.tsx`（日・週の画面）。テストは `e2e/calendar-views.spec.ts`・`e2e/calendar-views.mobile.spec.ts`・`tests/unit/calendar-view.test.ts`。
