# 勤怠・業務報告・給与明細

画面は `/work`（ナビの「勤怠・給与」）。人ごとの区分によって使える機能が変わります。

## 区分（6択）

ユーザーごとに管理者が「役員 / 正社員 / パート / 派遣 / 従業員 / 業務委託」を設定します（`/work` → 管理 → 区分・設定）。新規ユーザーの既定は「従業員」。

| 区分 | 使える機能 |
| --- | --- |
| 正社員 / パート / 従業員 | 打刻（出勤・休憩開始/終了・退勤）、月次の勤怠一覧と集計、給与明細 |
| 派遣 | 打刻・勤怠は同じ。明細は「報酬明細」（派遣元に支払うのは給与ではなく費用のため） |
| 業務委託 | 業務報告書の提出・編集・削除、報酬明細 |
| 役員 | 報酬明細 |

「従業員」は最初からあった区分で、細かい分け方をしない人向けに残してあります（既存のユーザーは変わりません）。
使える機能は `src/lib/work.ts` の `usesAttendance` / `usesReports` / `paysSalary` の3つで決まっています（区分を増やすときはここだけ直します）。

管理者（`role = admin`）は区分に関係なく「管理」タブが使えます。

## 締め日・振込日（区分ごと）

`/work` → 管理 → 「締め日・振込日」で、区分（役員・正社員・パート・派遣・従業員・業務委託）ごとに決めます（管理者と経理担当）。

| 項目 | 内容 |
| --- | --- |
| 締め日 | 末日、または1〜28日 |
| 支払月 | 当月・翌月・翌々月（締めた月から数える） |
| 振込日 | 末日、または1〜28日 |
| 土日のとき | 前の平日（金曜）に早める／次の平日（月曜）に遅らせる／そのまま（祝日は考えません） |
| 経費の申請期限 | 締め日の何日後まで（0〜31） |
| 業務報告書の提出期限 | 締め日の何日後まで（0〜31。業務委託の行だけ） |

初期値は「末日締め・翌月25日払い・土日は前倒し・期限は5日後」（業務委託だけ翌月末日払い）。設定がない区分は初期値で動きます（`pay_schedules` テーブル、`src/lib/pay-schedule.ts` に日付の計算）。

- 期間は「締めた月」の名前で呼びます（15日締めなら10月分は 9/16〜10/15）。支払日は、その月の次に支払月・振込日を当てはめた日です（末日締め翌月25日払いなら、10月分は 11/25）。
- **経費・業務報告書**: 期限までに出した分はその期間の締めに入り、期限を過ぎた分は次の期間（1回分遅れた支払い）になります。画面には「返金の予定」「期限後の提出 → ○月分」と出ます。決まる日付は保存せず、設定を変えると未払いの分は新しい設定で計算し直されます。
- **給与・報酬の明細**: 登録画面の支払日は、その人の区分の振込日が初期値で入ります（手で直せます）。立替金を明細に合算して新しく作る明細にも同じ日が入ります。
- **全銀データ**: 選んだ明細の支払日のうち、いちばん早い日が「振込指定日」の初期値になります。

## 勤怠

- 打刻は本人のみ（勤怠のある区分）。日付は日本時間で判定し、日をまたぐ勤務は未退勤の記録に退勤を付けます。
- 集計: 出勤日数 / 総労働時間 / 残業時間（所定労働時間を超えた分）。
- 設定（管理者）: 所定労働時間（既定480分）、自動休憩（既定60分。休憩を打刻しなかった6時間以上の勤務から差し引く。0で無効）。
- 管理者は従業員の記録を追加・修正・削除できます。修正した行には「修正済」が付き、監査ログに残ります。

## 業務報告書（業務委託）

日付・件名・内容・稼働時間（任意）。本人は自分の分のみ閲覧・編集、管理者は全員分を閲覧・削除できます。

## 給与・報酬明細

- 管理者が「支給」「控除」の項目ごとに登録します（金額は0以上の整数＝円）。差引支給額（手取り）= 支給合計 − 控除合計 は自動計算。
- 状態は「支払予定 / 支払済」。画面上部に、当月の**支払予定額**（未払いの手取り合計）と支払済額を表示します。管理者の管理画面では全員分の合計です。
- 本人は自分の明細だけ見られます（管理者でも「給与明細」タブは自分の分のみ。他人の分は「管理」から）。
- 賞与なども「名称」を変えて同じ月に複数登録できます。

## 注意

- 税・社会保険料の自動計算はしません。金額は管理者が入力した記録です。
- 勤怠・給与データはDBに平文で保存されます。アクセスはAPIで本人と管理者に限定していますが、バックアップやDBアクセス権の管理に注意してください。
- 労働基準法上の勤怠管理の要件（客観的記録の保存期間・36協定・割増賃金計算など）を満たすことを保証するものではありません。

## 通知

業務報告書の提出（管理者へ）、給与・報酬明細の登録/支払済（本人へ・金額なし）、管理者による勤怠修正（本人へ）はMattermostのDMで通知されます。詳細は `19_expenses.md` の「Mattermost通知」を参照。
